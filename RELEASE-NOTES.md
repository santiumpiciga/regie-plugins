Plugins de servidor de Regie.gg (CS2 y CS 1.6), con su código fuente.

- `regie-cs2-plugin-*.zip`: plugin de CounterStrikeSharp compilado, con la licencia y `fuente/`.
- `regie-cs16-plugin-*.zip`: plugin de AMX Mod X compilado, con la licencia y `fuente/`.
- `SHA256SUMS.txt`: la huella SHA-256 de cada zip.

Licencia GPL-3.0 o posterior (`GPL-3.0.txt` en cada zip). El código fuente de este
Release es el de cada `fuente/` y el que GitHub arma del tag.
